功能特性

一套完整的实时翻译工作流

从声音采集到译文输出，每一步都为低延迟与可读性而设计。

双向分路识别

麦克风与系统回环分两路独立识别：你的发言向外翻译，队友的语音向内翻译，双流并行互不干扰。

麦克风 · 系统回环 识别引擎 译文输出

多引擎识别

本地 Whisper（tiny / base / small）开箱即用，也可接入 DashScope、Soniox、SiliconFlow、MiMo 或任何 OpenAI 兼容接口。

AI 口语化朗读

出站译文先经 LLM 改写得更自然口语，失败自动降级原文，经虚拟声卡直接送入游戏麦克风。

VRChat 深度联动

译文直写 Chatbox，MuteSelf 状态自动联动，支持第二目标语言并列显示；启动时自动检查更新。

Chatbox 输出 MuteSelf 联动 第二目标语言

桌面 & SteamVR 字幕

顶层悬浮字幕随手拖动定位，头显内字幕支持 SteamVR / OpenVR，简体中文输出统一字形。

说话人标签

本地聚类或云端 speaker ID，多人混聊也能分清谁在说；云端 ID 配置后自动生效。

凭据安全存储

API Key 与自定义请求头经 DPAPI 加密存储，凭据不出本机，日志应用内可查并落盘。

技术亮点

为低延迟而生的工程

  • 本地优先的语音识别

    默认本地 Whisper 识别，无需联网、无需 API Key，语音数据不出设备。

  • 独立 .NET 引擎

    UI 与引擎分离架构：WASAPI 采集、Whisper.net、sherpa-onnx 多路 ASR / 翻译 / TTS 并行。

  • OSC 与 OpenVR 集成

    VRChat OSC 直写 Chatbox 与 MuteSelf 状态，OpenVR 头显内字幕随手势可见。

  • 全局快捷键

    Ctrl+Alt+Space 开始 / 停止，Ctrl+Alt+Enter 翻译当前输入，全程不打断游戏。

ENGINE PIPELINE

  1. 01

    采集 · WASAPI

    麦克风与系统回环双路采集，可断句、可路由

  2. 02

    识别 · Whisper / 云端 ASR

    本地 Whisper 与六家云端引擎自由切换

  3. 03

    翻译 · 免密链路 + LLM

    免密翻译开箱即用，可选 LLM 润色更口语

  4. 04

    输出 · Chatbox / TTS / 字幕

    文字写入 Chatbox，语音经虚拟声卡入麦，字幕悬浮桌面与头显

快速上手

三分钟，从下载到开译

01

下载安装

从 Releases 获取安装包或便携包，安装至当前用户目录，无需管理员权限。

02

选择引擎与设备

默认本地 Whisper 开箱即用；需要更高精度时，在模型服务页切换云端引擎。

03

开始翻译

Ctrl+Alt+Space 开始会话，译文实时写入 Chatbox，或经虚拟声卡送入游戏语音。
